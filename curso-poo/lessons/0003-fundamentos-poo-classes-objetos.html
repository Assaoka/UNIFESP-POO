Aula 3: Fundamentos de POO — Classes, Atributos, Métodos e Coleções

Nesta aula, convertemos os modelos das notas de aula para TypeScript moderno e destrinchamos exatamente como instâncias interagem com atributos e métodos. Esta aula prepara você para as Questões 3 e 8 da prova.

1. O Modelo Mental: Classe vs Instância (Objeto)

Classe: É o molde, planta arquitetônica ou definição abstrata de uma estrutura de dados e comportamento. Define quais atributos (estado) e métodos (comportamento) os objetos terão.

Instância (Objeto): É o elemento concreto alocado na memória, gerado a partir do molde da classe através da palavra-chave new.

Construtor (`constructor`): É o método especial executado automaticamente no instante em que o objeto é instanciado para inicializar os atributos daquele objeto específico.

2. Análise Passo a Passo do Código da Questão 8

class Pessoa {
  nome: string;
  idade: number;

  // Construtor: inicializa os atributos do objeto
  constructor(nome: string, idade: number) {
    this.nome = nome;
    this.idade = idade;
  }

  // Método de instância: comportamento acessível pelo objeto
  saudacao(): string {
    return `Olá, meu nome é ${this.nome} e tenho ${this.idade} anos.`;
  }
}

// Instanciação: 'p1' é um objeto concreto (instância) de 'Pessoa'
const p1 = new Pessoa("Alice", 30);
console.log(p1.saudacao());

O que é o que aqui?

  • Pessoa é a classe (o molde).
  • p1 é uma instância (objeto) da classe Pessoa.
  • nome e idade são atributos / campos de instância.
  • saudacao é um método da classe.
  • constructor é a função construtora responsável pela inicialização.

3. Composição de Classes e Coleções: Rastreando a Questão 3

Na orientação a objetos, objetos frequentemente compõem outros objetos. Veja a classe Carrinho que gerencia uma lista de Produto:

class Produto {
  nome: string;
  preco: number;
  tags: string[];

  constructor(nome: string, preco: number, tags: string[] = []) {
    this.nome = nome;
    this.preco = preco;
    this.tags = tags;
  }

  aplicarDesconto(percentual: number): void {
    this.preco -= this.preco * (percentual / 100);
  }
}

class Carrinho {
  produtos: Produto[];

  constructor(produtos: Produto[] = []) {
    this.produtos = produtos;
  }

  calcularTotal(): number {
    return this.produtos.reduce((acc, p) => acc + p.preco, 0);
  }

  toString(): string {
    return `Carrinho: ${this.produtos.length} produtos, Total: R$${this.calcularTotal().toFixed(2)}`;
  }
}

Rastreamento Minucioso da Execução (Teste de Mesa):

  1. produto1 = new Produto("Camisa", 49.90, ["roupa", "moda"]); → Preço inicial: 49.90.
  2. produto2 = new Produto("Tênis", 120.00, ["calçado", "esporte"]); → Preço: 120.00.
  3. produto3 = new Produto("Camisa", 100.00, ["formal"]); → Preço: 100.00 (Atenção: produto3 NUNCA é adicionado ao carrinho!).
  4. produto1.aplicarDesconto(10); → Desconto de 10% em 49.90 = 4.99. Novo preço de produto1: 49.90 - 4.99 = 44.91.
  5. carrinho = new Carrinho([produto1, produto2]); → O array contém 2 produtos (produto1 e produto2).
  6. Cálculo do total: 44.91 + 120.00 = 164.91.
  7. Saída final de carrinho.toString(): "Carrinho: 2 produtos, Total: R$164.91".
